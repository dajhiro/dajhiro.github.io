## 종류
### 전통적인 서버 방식
- EC2, VM 등에 `nohup` 또는 `systemd` 서비스로 등록해서 실행
	- `/etc/systemd/system/myapp.service`

### Docker(Container) 기반
- Dockerfile로 이미지 빌드 (JDK 베이스 이미지 + JAR COPY)
- 이미지를 Docker Hub, ECR, GCR 등 레지스트리에 푸시
- 이후 아래 중 하나로...
	- K8s(Kubernetes): 대규모 서비스, 오토스케일링/롤링 배포 요구 시
	- AWS ECS/Fargate: 관리형 컨테이너 오케스트레이션
	- 단순 Docker Compose: 소규모

### PaaS/Serverless

### Monorepo
프론트엔드/백엔드/공유 라이브러리를 한 저장소에서 관리
- 타입, 유틸 함수, 스키마 등을 패키지로 공유 가능
- 하나의 커밋으로 FE/BE 를 동시에 변경 가능
- 빌드/CI/CD 파이프라인 통합
